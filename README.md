# 📊 Business Intelligence & Data Analytics Projects

Bienvenue sur mon portfolio de projets **Business Intelligence, Data Analytics et Data Engineering**.

Ce repository regroupe plusieurs projets réalisés dans le cadre de ma formation, de mes stages et de mes travaux personnels. Ils couvrent différentes étapes du cycle de vie de la donnée : **collecte, nettoyage, transformation, modélisation, analyse et visualisation**.

L'objectif principal est de transformer des données brutes en **informations exploitables et indicateurs pertinents** pour faciliter l'analyse et la prise de décision.

---

## 🎯 Objectif

Ces projets mettent en pratique différentes technologies et méthodes utilisées dans les environnements **Data & Business Intelligence** :

- 📊 Analyse et exploration des données
- 🧹 Nettoyage et transformation des données
- 🔄 Développement de processus ETL / ELT
- 🗄️ Conception de modèles de données
- 🏢 Développement de Data Warehouses
- 💻 Développement de requêtes SQL
- 🐍 Analyse avec Python
- 📈 Création de rapports et dashboards interactifs
- 🎯 Définition et suivi des KPIs
- ⚙️ Automatisation des traitements de données

# 📁 Projects

## 1. 📈 Advertising Performance Analytics

Solution décisionnelle permettant de centraliser et d'analyser les performances de campagnes publicitaires.

### 🎯 Objectifs

- Centraliser les données provenant de différentes sources
- Nettoyer et transformer les données
- Calculer les principaux KPIs publicitaires
- Analyser les performances des campagnes
- Mettre en place des dashboards interactifs

### 📊 KPIs analysés

- Impressions
- Clicks
- CTR
- CPC
- Cost
- Conversions
- ROI
- Performance des campagnes

### 🛠️ Technologies

`Python` `SQL Server` `Power BI` `DAX`

---

## 2. 🏭 Business Intelligence — Production & Quality

Solution BI développée dans le cadre d'un projet de stage, permettant d'analyser les données de production et de qualité pour les entreprises textile.

### 🎯 Objectifs

- Centraliser les données opérationnelles
- Mettre en place des processus ETL
- Construire un modèle décisionnel
- Suivre les indicateurs de production et de qualité
- Créer des tableaux de bord pour faciliter l'analyse

### 🛠️ Technologies

`SSIS` `SQL Server` `MySQL` `Python` `Power BI`
